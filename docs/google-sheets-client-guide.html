Configurá tu
propio registro
de pedidos.

Una guía paso a paso para pasar el Google Sheet de pedidos a tu propia cuenta — no necesitás saber de programación. Cada paso explica qué hace y por qué importa.

Qué cubre Google Sheets + el script que registra los pedidos
Tiempo necesario Unos 15–20 minutos, desde una computadora (no un celular)
Necesitás Una cuenta de Gmail
01 · El panorama general

Por qué estás haciendo esto

Cada vez que alguien hace un pedido en tu sitio web, ese pedido necesita quedar registrado en algún lugar donde vos lo puedas ver: qué se compró, cuánto costó, cómo se pagó y si ya se entregó. Un Google Sheet es ese libro de registro. Es gratuito, se abre desde el celular o la computadora, y —lo más importante— una vez que vive en tu propia cuenta de Google, es tuyo. Podés revisarlo, respaldarlo o entregárselo a un nuevo desarrollador en cualquier momento, sin pedirle permiso a nadie.

Ahora mismo, mientras se construía el sitio, ese libro de registro estaba en la cuenta de Google del desarrollador para poder hacer pruebas sin molestarte. Esta guía explica cómo moverlo —junto con el pequeño "script" que lo alimenta— a tu cuenta. Pensá en el script como un cartero: es la pieza que recoge cada pedido del sitio web y lo deja en la fila correcta de tu Sheet. También necesita vivir en tu cuenta, porque de lo contrario el desarrollador sería técnicamente quien "tiene el buzón" de los datos de tus ventas.

En una frase
Estás copiando una hoja de cálculo ya armada a tu propio Google Drive, y activando el pequeño ayudante automático que permite que tu sitio web deposite cada pedido nuevo directamente ahí.
02 · Antes de empezar

Qué tener listo

Nada técnico — solo unos minutos y la cuenta correcta iniciada.

Una cuenta de Gmail — personal o de negocio, la que quieras que sea "la" cuenta del negocio de aquí en adelante. Si no tenés una, creala primero en gmail.com — toma dos minutos.
Una computadora, no un celular — la pantalla de configuración (llamada "Apps Script") es más fácil de usar desde una laptop o computadora de escritorio.
Una idea de contraseña — vas a definir una palabra o frase secreta durante la configuración. Elegí algo que solo vos sepas; no hace falta que sea complicada.
Al desarrollador a mano (WhatsApp está bien) — al final, le vas a mandar un enlace y una contraseña para que el sitio sepa dónde entregar los pedidos.
03 · Configuración

Paso a paso

Hacé estos pasos en orden. Ninguno es irreversible de forma peligrosa — si algo se ve raro, parate y escribile al desarrollador en lugar de adivinar.

1
Abrí la hoja de cálculo que te comparte el desarrollador
Vas a recibir un enlace de Google Sheets. Abrilo estando conectado a tu cuenta de Gmail, y luego andá a Archivo → Hacer una copia. Esto crea un duplicado que te pertenece por completo y lo guarda en tu propio Google Drive.
Por qué: "Hacer una copia" es la diferencia entre pedir prestado el cuaderno de otra persona y tener el tuyo propio. La copia mantiene todo el formato y las fórmulas existentes, pero ahora vive en tu Drive, no en el de ellos.
2
Renombrala
Renombrá la copia a algo como "Vency Atelier · Ventas" (clic en el título arriba a la izquierda, junto al logo de Sheets).
Por qué: Solo para que la reconozcas fácil en tu Google Drive. No hace falta anotar ningún identificador ni dirección — el código de esta guía encuentra la hoja solo, automáticamente.
3
Abrí el editor del script y pegá el código
Desde tu hoja copiada, andá a Extensiones → Apps Script. Se abre una nueva pestaña con un editor de código — no te preocupés, no vas a escribir código vos, solo copiar y pegar.
Si ya hay código ahí (porque venía incluido en la copia), seleccionalo todo (Ctrl+A) y borralo. Después andá al Apéndice al final de esta guía, copiá el bloque completo de código, pegalo en el editor vacío, y presioná Ctrl+S (o Cmd+S en Mac) para guardar.
Por qué: Este código es el que lee y escribe en tu hoja — sin él, la hoja es solo una tabla vacía. No hay ninguna línea que tengas que editar a mano: el script encuentra tu hoja de cálculo solo, porque corre adentro de ella.
4
Ejecutá el comando de configuración inicial
En la parte superior de la pantalla de Apps Script hay un menú desplegable con nombres de funciones y un botón Ejecutar (▶). Elegí setupSheets del menú, y luego hacé clic en Ejecutar.
La primera vez que hagas esto, Google va a mostrar una pantalla de permisos con una advertencia que se ve alarmante — algo como "Google no verificó esta app." Esto es normal: hacé clic en Avanzado, luego en Ir a [nombre del proyecto] (no seguro), y luego en Permitir.
Por qué: "Ejecutar" una función es simplemente hacer clic en un botón que le dice a la computadora "hacé esta tarea ahora." setupSheets crea automáticamente las dos pestañas que necesitás —Ventas e Inventario— con sus encabezados, para que no las tengas que armar a mano. La advertencia que da miedo aparece solo porque este script lo escribió tu desarrollador y no está publicado en una tienda de aplicaciones; como podés ver exactamente qué hace y confiás en quien lo escribió, es seguro permitirlo.
5
Definí tu contraseña secreta
Todavía en la pantalla de Apps Script, hacé clic en el ícono de engranaje ⚙ Configuración del proyecto a la izquierda, bajá hasta Propiedades del script, y hacé clic en Añadir propiedad de script. En el campo "Propiedad" escribí TOKEN, y en el campo "Valor" escribí tu propia contraseña secreta. Hacé clic en Guardar propiedades del script.
Por qué: Esta contraseña es lo que le dice al sistema "esta solicitud realmente viene de mí, la dueña del negocio" en vez de "esto es solo el navegador de una clienta." Es lo que protege tus números de ventas e inventario de que cualquiera los pueda cambiar. Guardala en un lugar seguro — vas a necesitar darle esta misma palabra al desarrollador en el último paso.
6
Publicalo como "aplicación web"
Hacé clic en el botón azul Implementar (arriba a la derecha) → Nueva implementación. Hacé clic en el ícono de engranaje junto a "Seleccionar tipo" y elegí Aplicación web. Completá:
Ejecutar como: Yo Quién tiene acceso: Cualquier usuario
Hacé clic en Implementar, y luego en Autorizar acceso si te lo pide (la misma advertencia de "no seguro" de antes — hacé clic de la misma manera). Cuando termine, vas a ver una URL de la aplicación web — copiá ese enlace completo.
Por qué: Publicarlo "como aplicación web" convierte tu hoja de cálculo en algo que puede recibir mensajes de internet —específicamente, de tu sitio web, cada vez que una clienta hace un pedido. "Ejecutar como: Yo" significa que actúa con tus permisos para escribir en tu propia hoja. "Quién tiene acceso: Cualquier usuario" suena alarmante, pero no significa que cualquiera pueda leer tu hoja — solo significa que el sitio web tiene permiso de tocar esta puerta específica para dejar un pedido. Nadie puede abrir tu hoja de cálculo real sin estar conectado a tu cuenta de Google.
7
Enviale dos cosas al desarrollador
Escribile al desarrollador (WhatsApp está bien) con:
1. La URL de la aplicación web que acabás de copiar 2. La contraseña secreta (TOKEN) del Paso 5
Por qué: El desarrollador necesita colocar ese enlace y esa contraseña en el código del sitio web para que los pedidos empiecen a llegar a tu hoja en vez de a la de ellos. Esta es la única información que necesitan de vos — nunca necesitan tu contraseña de Google ni acceso a tu cuenta.
8
Probalo juntos
Una vez que el desarrollador confirme que el sitio web quedó actualizado, hacé un pedido de prueba pequeño (o pedile que te guíe en uno). Abrí la pestaña Ventas de tu hoja y confirmá que apareció una fila nueva con los datos del pedido de prueba.
Por qué: Esta es la prueba de que todo está conectado correctamente antes de que empiecen a llegar clientas reales. Si no aparece nada, no intentes resolverlo sola — escribile al desarrollador con una captura de pantalla de tu editor de Apps Script.
04 · Con qué vas a quedar

Las dos pestañas dentro de tu hoja

Ejecutar setupSheets en el Paso 4 construye las dos automáticamente, con sus encabezados — no las creás a mano.

Pestaña Para qué sirve
Ventas Una fila por pedido: referencia, fecha, hora, artículos, total, método de pago, entrega, canal (Web o Local), clienta y estado (pendiente, confirmado o cancelado). Se llena automáticamente conforme llegan los pedidos.
Inventario Cuánto aceite de fragancia te queda de cada aroma, en mililitros, más el porcentaje de concentración de cada uno. Baja automáticamente cada vez que se vende un frasco o un decant. Las celdas resaltadas en rojo significan que ese aroma está agotado.
Podés mirar siempre, nunca se rompe con solo mirar
Abrir la hoja y navegar por ella es completamente seguro. Las únicas cosas con las que hay que tener cuidado: no borrar la fila de encabezados (fila 1) de ninguna pestaña, y no editar manualmente la columna A de la pestaña Inventario — el sistema la genera automáticamente.
Si alguna vez necesitás cambiar tu contraseña
Volvé a Apps Script → el ícono de engranaje ⚙ Configuración del proyecto → Propiedades del script → editá el valor junto a TOKEN. Solo acordate de avisarle al desarrollador el nuevo valor, ya que también está escrito en el panel de vendedor del sitio web.
05 · Apéndice

El código completo para pegar

Este es el código que va en el Paso 3. No necesitás entenderlo — solo copiarlo completo y pegarlo en el editor de Apps Script, reemplazando lo que haya ahí.

Recordá
No hay ninguna línea que tengas que cambiar a mano en este código. Pegalo tal cual y seguí al Paso 4.
/** * Vency Atelier — backend de Google Apps Script * * CONFIGURACIÓN: * 1. Abrí tu Google Sheet → Extensiones → Apps Script → pegá este archivo. * 2. Ejecutá setupSheets() una vez para crear las dos hojas con encabezados. * 3. Andá a Configuración del proyecto → Propiedades del script → agregá: * TOKEN = * 4. Implementar → Nueva implementación → Aplicación web * Ejecutar como: Yo * Quién tiene acceso: Cualquier usuario * 5. Copiá la URL /exec y pegásela al desarrollador. * 6. Volvé a implementar (Gestionar implementaciones → Editar) si el desarrollador actualiza este código. * * ESTRUCTURA DE LA HOJA * ───────────────────────────────────────────────────────────── * Ventas A:ref B:fecha C:hora D:items E:total * F:pago G:entrega H:canal I:cliente J:estado * * Inventario A:key B:nombre C:oil_ml D:pct * ───────────────────────────────────────────────────────────── */ var TZ = 'America/Costa_Rica'; var SHEET_VENTAS = 'Ventas'; var SHEET_INV = 'Inventario'; /* ── Enrutador de solicitudes ────────────────────────────── */ function doPost(e) { try { var data = JSON.parse(e.postData.contents); // Verificación de contraseña var token = PropertiesService.getScriptProperties().getProperty('TOKEN'); if (!token || data.token !== token) { return text('unauthorized'); } var action = data.action; // Sin acción = registrar una venta nueva if (!action) return registerSale(data); switch (action) { case 'summary': return summary(data); case 'inventory': return inventory(); case 'stock': return updateStock(data); case 'confirm': return confirmSale(data); case 'cancel': return cancelSale(data); case 'addCatalogEntry': return addCatalogEntry(data); default: return text('unknown action: ' + action); } } catch (err) { return text('error: ' + err.message); } } // Chequeo de salud / CORS function doGet() { return text('ok'); } /* ── Ayudantes ───────────────────────────────────────────── */ function text(s) { return ContentService.createTextOutput(String(s)); } function json(obj) { return ContentService .createTextOutput(JSON.stringify(obj)) .setMimeType(ContentService.MimeType.JSON); } function sheet(name) { return SpreadsheetApp.getActiveSpreadsheet().getSheetByName(name); } function today() { return Utilities.formatDate(new Date(), TZ, 'yyyy-MM-dd'); } function nowDate() { return new Date(); } function pad2(n) { return n < 10 ? '0' + n : '' + n; } /* ── Registrar venta ─────────────────────────────────────── */ function registerSale(data) { var s = sheet(SHEET_VENTAS); var now = nowDate(); var fecha = Utilities.formatDate(now, TZ, 'yyyy-MM-dd'); var hora = Utilities.formatDate(now, TZ, 'HH:mm'); // Los pedidos web arrancan "pendiente" hasta que se confirman a mano var estado = (data.canal === 'Web') ? 'pendiente' : 'confirmado'; s.appendRow([ String(data.ref || ''), fecha, hora, String(data.items || ''), Number(data.total || 0), String(data.pago || ''), String(data.entrega || 'En sitio'), String(data.canal || 'Local'), String(data.cliente || ''), estado ]); return text('ok'); } /* ── Resumen (métricas + lista de ventas + calendario diario) ── */ function summary(data) { var s = sheet(SHEET_VENTAS); var rows = s.getDataRange().getValues(); var period = data.period || 'hoy'; var now = nowDate(); // Resuelve el rango de fechas del período var todayStr = today(); var rangeStart, rangeEnd; if (period === 'hoy') { rangeStart = rangeEnd = todayStr; } else if (period === 'semana') { var dow = now.getDay(); // 0 = domingo var start = new Date(now); start.setDate(now.getDate() - dow); rangeStart = Utilities.formatDate(start, TZ, 'yyyy-MM-dd'); rangeEnd = todayStr; } else { // mes var mp = data.month || Utilities.formatDate(now, TZ, 'yyyy-MM'); var parts = mp.split('-'); var y = parseInt(parts[0], 10); var m = parseInt(parts[1], 10); rangeStart = y + '-' + pad2(m) + '-01'; var lastDay = new Date(y, m, 0).getDate(); rangeEnd = y + '-' + pad2(m) + '-' + pad2(lastDay); } // Mes de calendario para el mapa de calor diario (siempre el mes solicitado) var calMonth = data.month || Utilities.formatDate(now, TZ, 'yyyy-MM'); var cp = calMonth.split('-'); var cy = parseInt(cp[0], 10); var cm = parseInt(cp[1], 10); var calStart = cy + '-' + pad2(cm) + '-01'; var calLast = new Date(cy, cm, 0).getDate(); var calEnd = cy + '-' + pad2(cm) + '-' + pad2(calLast); // Totales var total = 0, web = 0, local = 0, efectivo = 0, sinpe = 0, webPendiente = 0; var fragrances = {}; var sales = []; var daily = {}; for (var i = 1; i < rows.length; i++) { var row = rows[i]; var ref = String(row[0] || '').trim(); if (!ref) continue; var fecha = ''; try { fecha = row[1] instanceof Date ? Utilities.formatDate(row[1], TZ, 'yyyy-MM-dd') : String(row[1]).substring(0, 10); } catch (_) { continue; } var hora = String(row[2] || ''); var items = String(row[3] || ''); var amt = Number(row[4] || 0); var pago = String(row[5] || ''); var entrega = String(row[6] || ''); var canal = String(row[7] || ''); var cliente = String(row[8] || ''); var estado = String(row[9] || 'confirmado'); if (estado === 'cancelado') continue; // Totales diarios de calendario (siempre para el mes que se muestra) if (fecha >= calStart && fecha <= calEnd) { daily[fecha] = (daily[fecha] || 0) + amt; } // Filtro de período if (fecha < rangeStart || fecha > rangeEnd) continue; // Acumulados total += amt; if (canal === 'Web') { web += amt; if (estado === 'pendiente') webPendiente += amt; } else { local += amt; } if (pago === 'Efectivo') efectivo += amt; else if (pago === 'SINPE') sinpe += amt; // Conteo de fragancias para el Top items.split(' | ').forEach(function (part) { // "Citrus Enigma · Decant 10 ml · EDT (10%)" → "Citrus Enigma" var name = part.split('·')[0].trim(); // Quita el prefijo "Set de 3 Decants (10 ml): " si está presente name = name.replace(/^Set de 3 Decants[^:]*:\s*/i, '').split(',')[0].trim(); if (name) fragrances[name] = (fragrances[name] || 0) + 1; }); // Vista previa de items (solo la primera línea; raw tiene todo) var itemParts = items.split(' | '); var itemPreview = itemParts[0] || ''; sales.push({ ref: ref, fecha: fecha, hora: hora, items: itemPreview, raw: items, total: amt, pago: pago, canal: canal, estado: estado }); } // Más recientes primero sales.sort(function (a, b) { var da = a.fecha + a.hora; var db = b.fecha + b.hora; return da < db ? 1 : da > db ? -1 : 0; }); return json({ month: total, // "month" es el total del período, sin importar el nombre del período web: web, local: local, efectivo: efectivo, sinpe: sinpe, webPendiente: webPendiente, fragrances: fragrances, sales: sales, daily: daily }); } /* ── Inventario ──────────────────────────────────────────── */ function inventory() { var s = sheet(SHEET_INV); var rows = s.getDataRange().getValues(); var inv = {}; for (var i = 1; i < rows.length; i++) { var key = String(rows[i][0] || '').trim(); if (!key) continue; inv[key] = { oil_ml: Number(rows[i][2] || 0), pct: Number(rows[i][3] || 0) }; } return json(inv); } /* ── Actualizar stock ────────────────────────────────────── */ function updateStock(data) { var s = sheet(SHEET_INV); var rows = s.getDataRange().getValues(); // Arma un mapa clave → índice de fila (base 1 para getRange) var keyRow = {}; for (var i = 1; i < rows.length; i++) { var k = String(rows[i][0] || '').trim(); if (k) keyRow[k] = i + 1; } var updates = data.updates || []; updates.forEach(function (u) { var rowIdx = keyRow[String(u.key || '')]; if (!rowIdx) return; var cell = s.getRange(rowIdx, 3); // C = oil_ml var current = Number(cell.getValue() || 0); if (u.set_oil_ml !== undefined) { cell.setValue(Math.max(0, Number(u.set_oil_ml))); } else if (u.delta_ml !== undefined) { cell.setValue(Math.max(0, current + Number(u.delta_ml))); } }); return text('ok'); } /* ── Confirmar venta ─────────────────────────────────────── */ function confirmSale(data) { return setSaleStatus(data.ref, 'confirmado'); } /* ── Cancelar / eliminar venta ───────────────────────────── */ function cancelSale(data) { return setSaleStatus(data.ref, 'cancelado'); } function setSaleStatus(ref, status) { var s = sheet(SHEET_VENTAS); var rows = s.getDataRange().getValues(); for (var i = 1; i < rows.length; i++) { if (String(rows[i][0]).trim() === String(ref).trim()) { s.getRange(i + 1, 10).setValue(status); // J = estado return text('ok'); } } return text('not found'); } /* ── Agregar fragancia al catálogo (siembra filas de inventario) ── */ /** * La llama el panel de vendedor al aprobar una solicitud de catálogo de una clienta. * data: { brand, name, cat, gender, notes } * Agrega tres filas de inventario: decant, 30ml, 100ml. */ function addCatalogEntry(data) { var s = sheet(SHEET_INV); var brand = String(data.brand || '').trim(); var name = String(data.name || '').trim(); if (!brand || !name) return text('missing brand or name'); var prefix = brand + '|' + name; var nombre = brand + ' — ' + name; var oil = Number(data.oil_ml) || 0; var rows = s.getDataRange().getValues(); // Se salta si el primer formato ya existe for (var i = 1; i < rows.length; i++) { if (String(rows[i][0]).trim() === prefix + ':decant') { return text('exists'); } } s.appendRow([prefix + ':decant', nombre + ' · Decant', oil, 20]); s.appendRow([prefix + ':30ml', nombre + ' · 30ml', oil, 20]); s.appendRow([prefix + ':100ml', nombre + ' · 100ml', oil, 20]); return text('ok'); } /* ── Configuración inicial de la hoja ────────────────────── */ /** * Ejecutá esto una vez desde el editor de Apps Script (Ejecutar → setupSheets). * Crea las dos hojas con fila de encabezados si no existen. */ function setupSheets() { var ss = SpreadsheetApp.getActiveSpreadsheet(); // Ventas var ventas = ss.getSheetByName(SHEET_VENTAS); if (!ventas) { ventas = ss.insertSheet(SHEET_VENTAS); } if (ventas.getLastRow() === 0) { ventas.appendRow(['ref', 'fecha', 'hora', 'items', 'total', 'pago', 'entrega', 'canal', 'cliente', 'estado']); ventas.getRange(1, 1, 1, 10).setFontWeight('bold'); ventas.setFrozenRows(1); ventas.setColumnWidth(4, 400); // columna de items más ancha } // Inventario var inv = ss.getSheetByName(SHEET_INV); if (!inv) { inv = ss.insertSheet(SHEET_INV); } if (inv.getLastRow() === 0) { inv.appendRow(['key', 'nombre', 'oil_ml', 'pct']); inv.getRange(1, 1, 1, 4).setFontWeight('bold'); inv.setFrozenRows(1); inv.setColumnWidth(1, 260); inv.setColumnWidth(2, 220); } SpreadsheetApp.getUi().alert('Hojas creadas: ' + SHEET_VENTAS + ', ' + SHEET_INV); }
